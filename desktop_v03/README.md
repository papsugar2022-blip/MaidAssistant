# 透明桌面角色层

从仓库根目录运行 `main.py` 即可启动本目录的透明角色外壳。

- `character_layer.py`：2D 素材、视角、透明窗口区域和鼠标交互。
- `main.py`：聊天气泡、功能面板、托盘，以及对 V0.2 业务模块的复用。
- `verify_layer.py`：Windows 原生命中和透明合成验证。
- `verify_migration.py`：使用临时待办数据验证功能与托盘行为。

操作方式、验证命令、依赖和规划统一见[项目 README](../README.md)。默认显示层使用 V0.2 模块声明的 V1.2 蓝瞳立绘，不需要复制素材。

本层尚未接入真实 AI 或 3D 渲染器；高 DPI 质量和多屏交互仍需进一步验收。
